> 复现脚本：`tools/leakage_audit.py`、`tools/dup_stratified_analysis.py`

## 一、验证集是否泄露 → **没有**

五重独立证据：

| # | 检查项 | 结果 |
|---|---|---|
| 1 | 索引重叠 | `train∩val = 0`、`train∩test = 0`、`val∩test = 0`；三集并集 = **2880**（完整无遗漏） |
| 2 | 分层正确性 | 每类精确 **96 / 12 / 12**，24 类全部符合（不符类别数 = 0） |
| 3 | 索引对齐 | `meta.csv` 的 `label` 与 `y.npy` **完全一致**，X 与标签无错位 |
| 4 | 统计量来源 | 归一化 / 分位截断 / 死通道掩码**只从 `X_train` 计算**（`src/data/preprocess.py:215-216`），再套用到 val/test |
| 5 | 划分与测试集使用 | 划分**落盘持久化**（`dataset.py` 读 `meta.csv`，不重算）；测试集**仅在训练全部结束后评估一次**（`src/train.py:139`），训练中只用验证集做早停/选优 |

→ 不存在「同一样本同时出现在训练与验证」或「统计量从验证集泄漏到训练」的问题。

## 二、⚠️ 但发现更隐蔽的「近重复」效应（非划分错误，是数据本身）

在同一类别内，同一手势的多次重复采集**本身高度相似**，随机划分会让一些近乎重复的样本分处训练集与测试集。

实测（glove，flatten + 去均值 + L2 归一化后的余弦相似度）：

| 指标 | 数值 |
|---|---|
| 测试样本在训练集中的**最近邻相似度** | 均值 0.940，中位 0.965，**最大 1.0000** |
| **cos ≥ 0.999 的测试样本** | **79 / 288（27.4%）** |
| 其中同类 / 跨类 | **79 / 0**（无跨类近邻 → 不是标注错误） |
| cos ≥ 0.95 的测试样本 | 184 / 288（63.9%） |

**分层准确率（基线 bilstm_both，整体 98.61%）**：

| 子集 | n | 准确率 |
|---|---|---|
| 有近重复（cos ≥ 0.999） | 79 | **100.00%** |
| 无近重复 | 209 | **98.09%** |

→ 近重复把整体准确率抬高约 **+0.52 pp**。

**sEMG 模态下更明显**（整体 91.32%）：

| 子集 | n | 准确率 |
|---|---|---|
| 有近重复（cos ≥ 0.999） | 50 | **100.00%** |
| 无近重复 | 238 | **89.50%** |

→ 抬高约 **+1.82 pp**；且「无近重复」的 89.50% **更接近论文报告的 sEMG 单模态 88.02%**。

另：哈希比对发现 **1 组完全相同的文件** —— `Go/24.pkl` 与 `Go/25.pkl`。

**判断：近重复效应真实存在，应作为方法局限性如实写出；但它对 glove 只有 0.5 pp，远不足以解释与论文的 14 pp 差距。**

## 三、与论文差异的归因（按可能性排序）

**已排除**：数据泄漏（§一）、划分错误（§一）、标签错误（跨类近邻为 0）。

| # | 假说 | 依据 / 可验证性 |
|---|---|---|
| 1 | **论文单模态实验协议不同**（最可能） | 若其 Fig. S25 是「在训练好的融合模型上做测试时模态剪枝」（把另一支输入置零），性能会比「单独训练一个单模态模型」低得多。我们用的是后者。论文 Supporting Information 本地缺失，**无法核实**。 |
| 2 | 预处理差异 | 我们做了逐通道鲁棒归一化（1%/99% 截断）+ 8 个噪声底死通道置零，可能优于论文处理 |
| 3 | 论文数值来源不同 | 83.75% 或来自早期版本 / 不同规模实验 |
| 4 | 数据版本差异 | 无法排除 |

**本复现的排序（融合 > 仅手套 > 仅 sEMG）与论文一致，分歧只在"单模态的绝对值"与"融合增益幅度"。**

## 四、统计显著性提醒（须写入报告）

测试集仅 288 样本 → 95% 置信区间：

| 模型 | 准确率 | 正确数 | 95% CI |
|---|---|---|---|
| TCN | 99.65% | 287/288 | ±0.68 pp |
| 1D-CNN | 99.31% | 286/288 | ±0.96 pp |
| Bi-LSTM | 98.96% | 285/288 | ±1.17 pp |
| Bi-GRU | 98.61% | 284/288 | ±1.35 pp |

→ **Bi-LSTM 与 TCN 之间只差 2 个样本**，置信区间高度重叠。
→ 结论应写「各模型数量级相当」，**不应写成「TCN 显著优于 Bi-LSTM」**。

**可选加固方案**：关键对比跑 3~5 个随机种子，报告 mean ± std。可显著提升结论可信度（代价约 +3 小时 GPU）。
