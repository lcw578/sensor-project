# 阶段一：数据读取与预处理（设计说明）

> 本节内容可直接用于实验报告第 1 项「数据读取及预处理方法」与第 2 项「数据集划分方式」。

## 1. 数据读取

- 数据根目录：`24手语数据/data`（仓库内相对路径；数据集本体不入库，需自行放置），共 **24 个类别目录 × 120 个 `.pkl` = 2880 个样本**。
- 每个 `.pkl` 用 `pickle.load()` 读出的对象是 **Python dict，固定 4 个键**：

| 键 | 含义 | 原始 shape | dtype |
|---|---|---|---|
| `res1` | 左手应变/压力 | (20, 400) | float32 |
| `res2` | 右手应变/压力 | (20, 400) | float32 |
| `muscle1` | 左手 sEMG | (10, 1950) | float32 |
| `muscle2` | 右手 sEMG | (10, 1950) | float32 |

- 采样率：应变/压力 **200 Hz**、sEMG **1000 Hz**，单样本时长 **2 s**。
- 实测校验：2880 个文件形状 **100% 一致**，**无 NaN / Inf / 读取失败**。

## 2. 模态组装（对齐源论文）

同一模态的左右手在**通道维**拼接，并转为**时间主序**：

```
glove = concat([res1, res2], axis=0).T          -> (400, 40)    # 20+20 通道
semg  = concat([muscle1, muscle2], axis=0).T    -> (1950, 20)   # 10+10 通道
```

- 与源论文「400×40 应变/压力、2000×20 sEMG」一致（论文 2000 为约值，实际为 1950）。
- 两种模态时间点数不同（400 vs 1950）**属正常**，采用**双分支**网络分别提特征后融合，**不做**直接拼接或强制重采样。

## 3. 数据集划分（8:1:1）

- **以 `.pkl` 文件为最小单位**，**按类别分层**划分，每类 120 → 训练 96 / 验证 12 / 测试 12。
- 总计：**训练 2304 / 验证 288 / 测试 288**。
- 固定随机种子 `seed=42`，划分结果落盘为 `meta.csv`（含 `index, label, class, file, split`），**完全可复现**。
- **不做**同一文件内部的时间点拆分，从根源上杜绝数据泄漏。

## 4. 归一化与异常值处理

> 顺序：**先在训练集上求分位截断界 → 截断 → 在截断后的训练集上求 mean/std → 标准化**。
> 统计量**只来自训练集**，验证/测试集直接套用，避免信息泄漏。

1. **离群截断**：逐通道取训练集 **1% / 99% 分位**作为上下界，`clip` 掉极端尖峰。
   - 动因：实测应变/压力存在幅值达 **1514（res1）/ 3988（res2）** 的离群样本（常见样本仅个位数量级），不处理会主导通道方差。
2. **逐通道标准化（z-score）**：`x' = (x - mean_c) / std_c`，通道级统计量取自训练集。
3. **噪声底死通道置零**：全局 std 低于 `0.05` 的通道视为无效通道，标准化后**统一置 0**。
   - 实测识别出 **8 个**此类通道：拼接后索引 `[14, 15, 17, 18, 19, 20, 21, 22]`
     （左手 res1 的 14/15/17/18/19 + 右手 res2 的 20/21/22）。
   - 依据：这些通道「样本内 std ≈ 0.006、全局 std ≈ 0.016」，而有效通道全局 std 在 **0.3 ~ 93**，两者可干净区分（阈值 0.05）。
   - 目的：避免把噪声放大成"伪特征"。
4. 标准化后实测：glove `mean≈0.000 std≈0.90`、semg `mean≈-0.001 std≈1.00`，无 NaN。

## 5. 产物清单（`outputs/cache/`）

| 文件 | 内容 | 形状/说明 |
|---|---|---|
| `X_glove.npy` | 归一化后手套模态 | (2880, 400, 40) float32 |
| `X_semg.npy` | 归一化后 sEMG 模态 | (2880, 1950, 20) float32 |
| `X_glove_raw.npy` | 原始手套模态（未归一化，供实验对比） | (2880, 400, 40) |
| `X_semg_raw.npy` | 原始 sEMG 模态 | (2880, 1950, 20) |
| `y.npy` | 标签 | (2880,) int64, 0..23 |
| `meta.csv` | 索引/标签/类别/文件/划分 | 2880 行 |
| `label_map.json` | 类别名 → 标签 | 24 项, 字典序 |
| `norm_stats.npz` | 逐通道 mean/std/截断界/死通道掩码 | 供推理复用 |
| `preprocess_report.json` | 预处理超参与统计摘要 | 可复现审计 |

## 6. 复现命令

```bash
python src/data/preprocess.py                 # 默认配置（8:1:1, clip 1%~99%, 全局训练集标准化）
python src/data/preprocess.py --no-clip        # 关闭截断（对比实验）
python src/data/preprocess.py --norm-mode per_sample   # 逐样本标准化（对比实验）
```
