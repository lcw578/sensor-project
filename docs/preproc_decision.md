# 预处理决策分析：sEMG 滤波 & per-sample 标准化

> 方法：对 `outputs/cache/` 中 2880 个样本的原始 sEMG/手套数据做**只读频谱与方差结构诊断**，不修改任何流水线。
> 复现脚本：`tools/diag_semg_spectrum.py`；图：`outputs/figures/diag_semg_spectrum.png`。

---

## 0. 结论速览

| 问题 | 结论 |
|---|---|
| **sEMG 要不要带通滤波？** | **数据里确实有明确可滤除的干扰**（48.17 Hz 单音 + <20 Hz 漂移），信号质量上滤波合理。**做法：保留"不滤波"作论文复现基线，并行跑"带通 20–450 Hz + 陷波"版对比**，用实测准确率定去留。 |
| **per-sample 标准化要不要开？** | **不建议作主方案，更不建议两模态同时开。** sEMG 的**幅值本身有类判别性（F=2.88）**，逐样本 z-score 会把它抹掉；glove 幅值无判别性（0.135）且样本间 DC 偏移是动态的 3 倍，**只对 glove 用**才有理论收益。 |

## 1. sEMG 频谱诊断（实测）

| 频带 | 占总能量 |
|---|---|
| 0–1 Hz | 1.4% |
| **1–20 Hz**（漂移/运动伪迹） | **45.9%** |
| 20–50 Hz | 40.6% |
| 50–150 Hz | 9.3% |
| 150–450 Hz | 2.6% |
| 450–500 Hz（噪声） | 0.2% |
| **典型 sEMG 带 51–450 Hz** | **仅 11.2%** |

**发现 1：48.17 Hz 强单音干扰。**
- 频率 **48.17 Hz**，−3 dB 带宽仅 **0.50 Hz**（纯音特征）。
- 在原生分辨率下**单个频点占总能量 18.7%**；并在 96.3 / 144.5 / 192.7 / 240.9 Hz 出现**谐波尖峰** → 典型周期性工频/电子干扰。
- 逐样本占比：**中位 11.4%，P90 51.2%，最大 88.8%**；**26.4% 的样本 >30%**，55.1% 的样本 >10%。
- 频率偏离 50 Hz，若视作工频 50 Hz 被观测为 48.17 Hz，推算**实际采样率 ≈ 1038 Hz**（标称 1000 Hz 存在偏差）。
  → **设计陷波器必须打 48.17 Hz（及其谐波），按 50 Hz 设计会打偏、漏掉干扰。**

**发现 2：1–20 Hz 低频占 45.9%，且谱形平滑（无尖峰）** → 宽带基线漂移 / 运动伪迹，属非神经成分。

**发现 3：真正的神经性 sEMG 只占约 11%**（51–450 Hz）。

## 2. sEMG 滤波：利弊与推荐

| | 滤波（20–450 Hz 带通 + 48.17 Hz 陷波） | 不滤波 |
|---|---|---|
| **利** | 去除 ~46%(漂移)+~19%(工频) 的非神经成分；SNR↑；消除"随样本幅值波动的干扰维度"；符合 sEMG 标准流程 | 不引入人为处理；严格贴合论文（论文未提滤波）；保留伪迹中可能夹带的类别线索 |
| **弊** | 若伪迹本身携带类别信息则掉点；实现不当（非零相位）会引入相位失真；增加超参 | 26% 样本被工频主导；等效给模型注入随样本变化的干扰维度，可能压制上限 |
| **适用** | 生理信号 + 工频污染重（本项目） | 信号干净，或需严格对齐论文 |

**推荐方案（两条腿走）：**
1. **基线 = 不滤波**（严格对齐论文，论文未提滤波）。
2. **对照 = 带通 20–450 Hz（4 阶 Butterworth，零相位 `filtfilt`）+ 48.17 / 96.3 / 144.5 Hz 陷波**。
3. 对比结果本身就是报告第 1 项（预处理方法）与一组**预处理对比实验**的现成素材。
4. 预期：滤波版 **≥ 持平**；若基线明显低于论文 99.65%，**滤波应作为首选改进方向**。

## 3. per-sample 标准化：依据与推荐

类判别力 F = 类间方差 / 类内方差（越大越有判别性）：

| 模态 | 逐样本 RMS 幅值的类判别力 F | 样本间 DC / 样本内动态 |
|---|---|---|
| **sEMG** | **2.88**（幅值很有判别性） | 0.114（样本间偏移小） |
| **glove** | 0.135（幅值几乎无判别性） | **3.02**（样本间偏移是动态的 3 倍） |

**解读：**
- **sEMG：幅值携带类别信息**。per-sample z-score 把每样本每通道均值归零、标准差归一 → **正好抹掉该判别维度**；且其样本间偏移本就小（0.114），**收益小、损失明确 → 不该对 sEMG 用**。
- **glove：幅值不可分（0.135），但存在明显"每样本一个直流台阶"**（3.02）。per-sample 去均值**有理论收益**且**损失很小** → **只对 glove 试**。
- 现行**全局训练集 z-score 保留了样本间幅值差异**，对 sEMG 是正确选择。

**推荐方案：**
- 主方案保持**全局训练集 z-score**。
- 作为对比跑三条：① 全局 z-score（主）② per-sample 仅 glove ③ per-sample 两模态全开。
- **不要**把"两模态同时开 per-sample"当作默认改进 —— 对 sEMG 大概率**变差**。
