## 自绘页说明

- **页 2 时间线**：五个节点 = 数据体检 → 方法 → 主结果(key) → 四组实验 → 对照与局限

  （`tools/verify_report_numbers.py` 已核对 70 项）

## 排版要点（本次改版）

- 字体栈 Windows 优先：`Segoe UI + Microsoft YaHei`（模板默认苹果字体栈在 Windows 上掉宋体）
- 页数 27 → 19：砍掉 4 个过渡页，图与数字表并排（`.fig2`）提高单页信息量
- 表格里 colspan 行加了 `white-space:normal`，否则 nowrap 会撑爆最小宽度、挤扁并排图卡
- 架构图改全宽：半宽时图内文字缩到 ~8px，全宽恢复可读
