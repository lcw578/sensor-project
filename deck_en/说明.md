## 自绘页说明

- **#4 采样率不一致**：画两条时间轴（glove 200 Hz / sEMG 1000 Hz），长度不同 → 引出"不强行对齐、各自独立分支"的设计决定。
- **#5 预处理流水线**：四步方框（逐通道检查 → 1/99 分位截断 → 训练集统计量标准化 → 死通道置零），标注"统计量只来自训练集"与"顺序不可交换（反序 std=0.756）"。
- **#23 主导模态机制**：画梯度流示意——手套分支已把样本分开 → 分类头权重重心偏移 → sEMG 分支梯度趋零 → 分支冻结。右侧列出三组独立证据指向同一结论。

## 渲染脚本的两个 Windows 适配（已改进 render_preview.py）

1. headless Chrome 必须加独立的 `--user-data-dir`（多实例冲突时会**静默不产出文件**）。
2. `--screenshot` 必须用**绝对路径**（相对路径在 Python subprocess 下同样静默失败）。
3. 连续渲染 26 页偶发单页失败（第 23 页），单独重跑该页即可。
